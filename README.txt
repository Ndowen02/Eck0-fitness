FOREST TRAINING — INSTALLABLE WEBSITE

What's included
- Luxury dark forest / cream / gold mobile design
- Legs, Back + Biceps, Chest + Triceps, Rest day
- Check off every set
- 90-second rest timer auto-starts when a set is checked
- Adjustable rest timer in Settings
- Saves the last weight used for each exercise
- Saves completed workouts to History
- Saves Arc Trainer distance and calorie estimate
- Works offline after the first successful load when hosted

IMPORTANT
The app stores your workout data in your browser on your device using localStorage.
If you clear Safari website data, the saved history can be erased.

FASTEST WAY TO PUT IT ON YOUR IPHONE
1. Host this folder on any static-site host (GitHub Pages, Netlify, Vercel, Cloudflare Pages, etc.).
2. Open the hosted link in Safari on your iPhone.
3. Tap Share.
4. Tap Add to Home Screen.
5. Tap Add.

For GitHub Pages:
1. Create a new GitHub repository.
2. Upload every file in this folder to the repository root.
3. In GitHub: Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select the main branch and /(root), then Save.
6. Open the generated GitHub Pages URL in Safari and Add to Home Screen.
